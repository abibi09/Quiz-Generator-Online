# Quiz Generator Online

An interactive quiz generator built with Python and Streamlit for an AI & Data Science internship project.

## Features

- Generate quizzes from learning material entered by the user.
- Supports Multiple Choice, True/False, Fill in the Blank, and Mixed question types.
- Choose Easy, Medium, or Hard difficulty.
- Generate between 1 and 10 questions.
- Answer questions and view your quiz score.
- Download a quiz report and answer key in supported formats.

## Technologies Used

- Python
- Streamlit
- JSON and Python standard libraries

## Requirements

- Python 3.10 or newer
- Streamlit

## How to Run

1. Install Python on your computer.
2. Open a terminal in the project folder.
3. Install Streamlit:

   ```bash
   pip install streamlit
   ```

4. Start the application:

   ```bash
   streamlit run app.py
   ```

5. Open the local URL displayed in the terminal.

## How to Use

1. Enter or paste learning material into the application.
2. Select the question type and difficulty.
3. Choose the number of questions.
4. Generate the quiz and answer the questions.
5. Review your score and download the available reports.

## Project Purpose

This project demonstrates a simple, interactive way to create practice quizzes from educational text using Python and Streamlit.

**Note:** Question generation uses rule-based text processing and keyword matching. It does not require a trained machine-learning model.
